المميزات

كل ما تحتاجه لتواصل البرمجة حتى لو تعطّل أحد المزوّدين.

أي أداة، أي نموذج

وجّه Fable وOpus وSonnet وHaiku في Claude Code إلى أي نموذج مدعوم، من نفس قائمة /model.

أربع واجهات API

Anthropic Messages وOpenAI Chat Completions وOpenAI Responses وGemini. كل نموذج يعمل على كل واجهة.

موثوقية عالية

إعادة المحاولة تلقائيًا، وحدود معدل قابلة للضبط، وتحويل تلقائي بين النماذج والمزوّدين ومفاتيح API.

من الهاتف

نفّذ مهام البرمجة من Discord أو Telegram، وأرسل ملاحظات صوتية عبر Whisper.

تطبيقات ومحررات

Claude Desktop وCodex App وVS Code وJetBrains، تتصل بنقرة واحدة من لوحة التحكم.

توفير التوكنات

استهلاك أقل بنسبة تصل إلى 90% باستخدام RTK وHeadroom.

شغّل FCC

على Windows وmacOS افتح Free Claude Code من سطح المكتب. على Linux شغّل الأمر التالي. تُفتح لوحة التحكم تلقائيًا.

fcc-server

أضف مفتاح مزوّد

أنشئ مفتاحًا مجانيًا من NVIDIA NIM، ثم من لوحة التحكم افتح Providers ← NVIDIA NIM ← Add key ← Save ← Apply.

شغّل أداة البرمجة

fcc-claude    # Claude Code
fcc-codex     # Codex
fcc-opencode  # OpenCode

استخدام الواجهة البرمجية مباشرة

أي عميل أو SDK يمكنه الاتصال بـ FCC على http://127.0.0.1:8082 بعد تشغيله على جهازك.

curl http://127.0.0.1:8082/v1/messages \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nvidia_nim/nvidia/nemotron-3-ultra-550b-a55b",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
